# Automatic Payday 2 DLC Unlocker Tool

**P2DUnlocker** is an all-in one tool that automatically activates unlocks and downloads DLCs in **Payday 2**, both in multiplayer and single, modded and unmodded versions.

## **System Requirements**

- Windows 10 or Windows 11  
- Installed copy of *Payday 2*
- At least 2 GB free disk space  
- .NET Framework 4.8 or newer

---

## **How to Use**

1. Download the latest **Payday2-DLC-Tool** from the Releases page  
2. Run the application (no installation required)  
3. Select the path to your game
4. Choose your profile and save file  
5. Edit desired values  
6. Press **Save Changes**
